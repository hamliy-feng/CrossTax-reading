# 标杆案例搜集与验收指引

首批十例是五组业务场景，每组一例完整事实与一例边界反例。它们用于检索、引用、条件判断和回归，不直接冒充法院或税局的专业通过案例。现有 200 个模板保留原记录。

## 到哪里找、找什么

先查税务机关案例/问答、立法数据库、公开法院判决、税局裁定和官方算例。中国从国家税务总局法规库及协定目录查；新加坡从 IRAS 的 DTA 原件、扣缴税问答和 Singapore Statutes Online 查；香港从 IRD 内地安排、议定书、DIPN、司法判决查。事务所文章用于定位文件，最终结论必须返回原文。

| 案例 ID | 完整事实场景 | 边界反例 |
|---|---|---|
| CN-SG-EQUIP-01/02 | 中国向新加坡支付设备使用费；设备、合同权利和来源明确 | 实际是知识产权许可；设备名义不能套同一税基 |
| CN-SG-SOFTWARE-01/02 | 中国向新加坡支付软件许可费；复制/分发权等明确 | 合同只写软件费，许可、服务和销售无法分类 |
| SG-CN-DIVIDEND-01/02 | 新加坡向中国公司派息；居民、主体和支付事实明确 | 居民或资格材料不足；区分国内法豁免与协定资格 |
| SG-CN-INTEREST-01/02 | 新加坡向中国公司付息；债权、来源和无 PE 关联明确 | 所得与 PE 有效关联，转入其他规则分析 |
| CN-HK-DIVIDEND-01/02 | 中国向香港公司派息；持股和受益身份材料明确 | 持股/受益所有人/证明材料不足 |

新加坡股息场景必须检查国内法及 IRAS 说明：税收协定给出上限不意味着国内法一定扣税。居民材料缺失影响协定资格，不能据此反向认定所有股息必定征税。[IRAS 股息扣缴说明](https://www.iras.gov.sg/taxes/withholding-tax/payments-to-non-resident-company/payments-that-are-not-subject-to-withholding-tax)。

软件资料可参考 [IRAS 权利分类问答](https://www.iras.gov.sg/taxes/withholding-tax/payments-to-non-resident-company/payments-that-are-subject-to-withholding-tax)，但新加坡付款侧处理不能直接套用于中国付款侧。中新条款另查 [总局国税发〔2010〕75 号](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5194181/content.html) 和后续修改；香港查 [内地安排原文及议定书入口](https://www.ird.gov.hk/eng/tax/dta_cdta.htm)。

## 采用什么形式

找到完整公开事实时，记录真实案号、机关、日期、事实、争议、裁决、理由和有效版本。没有完整事实时，采用明确构造测试，记录构造来源和设定理由，`case_type=constructed_test`、`official_case_number=null`。官方解释可以作为依据，不得把自己设定的金额或企业名称写成官方事实。

案例不先填“优惠税率”再找支持；先确定方向、主体、税种、权利、所得分类、日期及例外，最后核对国内法与协定后的结果。缺失事实应产生追问或阻断，false 与 unknown 分别测试。

## 放在哪里

在私有项目 `research/benchmarks/<case_id>/` 保存：

```text
case.md                 事实叙述、真实/构造类型、场景与问题
facts.json              结构化事实；未知字段 null
sources.json            原件 URL/获取时间/SHA/文件定位
evidence.json           条号、物理页/段落、版本、摘录及研究边界
expected.json           预期识别/缺口/条件算例；不预设未证明税率
analysis.md             逐步法律问题、分类、公式、冲突和后续资料
actual.json             本次实际接口输入/输出、时间、代码版本
acceptance.json         程序断言、检索定位、结果及未完成检查
```

原件按 SHA 放在私有 `research/benchmarks/_sources/` 或既有 `research/raw/`，同一文件通过清单复用。公开包提供 URL/SHA、必要短摘录及案例说明，不公开原始全集。

## 怎样分析与验收

1. 从事实识别方向、居民与主体，读合同确定权利，不直接按文件名分类。
2. 查双方国内法，确定来源、税种、税基、豁免和程序；再查协定及所有变更。
3. 每一步记录原文定位和版本；研究指南仅说明线索。
4. 给出不确定事实、反例触发条件及补充材料；明确 PE 关联、居民不足、持股不足会改变哪一步。
5. 实际调用法律检索及税务接口；记录命中的证据 ID、SHA、公式、输入和输出。若模型不可用，模型运行记为未完成。
6. 对完整事实但无正式发布规则的案例，正确结果仍可能是 `rule_not_published` 和 `tax_estimate=null`。假设税率只有明确输入时才生成 `conditional_example`，不能计为专业税额通过。
7. 基准更新时保留旧预期及运行记录，重新运行，不覆盖历史。

## 如何进入产品

案例问题进入演示题库；事实字段用于智能追问和必要条件；证据用于 RAG 引文测试；完整/反例成对测试用于规则边界；已保存实际记录用于上线前回归。项目汇总可以读取这些案例形成分析报告，仍需保留原始来源和研究状态。

本期程序验证十案例的识别、缺口和正式税额阻断；法律适用的全部专业验收与模型独立检查分别统计，不把十个目录存在当作十例全部通过。
