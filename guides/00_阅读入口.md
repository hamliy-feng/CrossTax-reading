# Taxroute 阅读入口

本包帮助资料编写者和外部模型理解项目，并交付可以追溯到原文的研究资料。完整项目保留在私有仓库，公开包不包含用户聊天、凭据、数据库备份及原始资料全集。

## 产品与完成口径

目标用户是中国出海商家、财务人员及跨境研究者。产品同时提供普通对话、跨对话项目工作台和税务研究工具。税收协定资料是第一阶段底座；它不等于自由贸易协定、关税、商品原产地或全球国内税法覆盖。

2026-10-06 数据基线：历史官方目录 111 个伙伴、110 个已有原文；502 条 PDF 记录对应 499 个内容哈希；1593 条机器法条候选覆盖 55 个版本/54 个伙伴；115 份国别指南及 16139 个片段；21525 条 OECD 研究观测。L2 引用、L3 规则、正式发布包和专业通过案例均为 0。上述统计属于不同分母，不能合并成“全部完成”。

本期代码新增 FastAPI 工作台、项目、附件、消息分支、真实法律检索、计算接口、汇总及追问。具体本地测试、模型实测、云端访问分别记入 `STATUS.md`；代码存在不代表已上线。当前没有已发布的法律规则，程序只允许条件算例或列出缺口。

## 架构与资料层次

```text
原生 HTML/JS 三栏网页
  → FastAPI / NDJSON 流式网关
  → 主模型、独立追问模型、实际后端工具
  → crosstax_app：账号所属项目/消息/工具/证据快照/作品
  → crosstax：文献、版本、历史法条、指南、发布规则视图
  → 私有对象存储：原始附件与法律原件
```

官方原件证明文书内容；版本和适用资料确定交易日期下的效力；指南用于发现问题；统计用于比较研究。模型负责整理、交叉检查和表达，确定性程序负责数值与关联验收。正式发布视图仍按现有字段和真实检查条件使用，不写虚构审核人。

## 阅读顺序

1. 本文、`STATUS.md` 和 `SOURCE_VERSION.json`：目标、能力边界及代码版本。
2. `01_专业引用与规则发布执行指引.md`：交付法条引用和结构化规则的方法。
3. `02_标杆案例搜集与验收指引.md`：十个场景、材料形式和实际运行记录。
4. `03_Web工作台与云端部署方案.md`：接口、存储和部署步骤。
5. `04_智能追问接入与验收.md`：独立模型与推荐缓存。
6. `code/`、`schema/`、`indexes/official_sources.jsonl`：必要源码、结构和官方 URL/SHA 索引。

外部模型可直接读取 `ALL_CONTEXT.md`，或按 `CONTENTS.json` 中的原始正文链接连续读取。阅读包来自指定源提交，并提供文件 SHA；更新时重新生成版本清单。

## 任务分工与交接

| 顺序 | 执行者工作 | 必须交付 |
|---|---|---|
| 资料整理 | 找官方原件、验证字节 SHA、建立来源与版本索引 | 来源清单、原件存放位置、缺口 |
| 交叉检查 | 独立请求检查文书身份、条号、日期、条件和修订 | 核查报告、逐项证据、争议表 |
| 争议裁决 | 只用冲突原文与事实进行独立比较 | 已解决依据或保留争议，不投票生成事实 |
| 程序验收 | 复算 SHA、检查 JSON/SQL 关联、执行正反例 | 验收 JSON、失败项、实际运行记录 |

每次请求使用新上下文，保存实际服务商/模型 ID、请求时间、输入 SHA 和输出 SHA。默认使用项目已有 DeepSeek。一次模型同意不计为真实专业审核。

## 资料交付方式

外部编写者无需完整仓库权限即可阅读本包；把新增资料按模板放在自己的工作目录，交付 Markdown、JSON 和来源清单，或向阅读仓库提交 Pull Request。维护者在私有工程复算原件、执行 SQL 提案和回归后入库。公开仓库不接受数据库凭据、个人税务材料或私人聊天。

交付清单：五份文档、可读源码、数据库结构、官方索引、十案例目录、合并阅读文档、提交版本、公开访问记录；另交付实际工作台 HTTPS 和按功能拆分的验收记录。任何待配置服务保持待完成状态。

AI 可能会说错，请注意甄别。
