# Taxroute 公开阅读包

产品现名 Taxroute，正式网站 https://taxroute.online/。本包保留 SOURCE_VERSION.json 所记源提交的代码快照；本次仅更新展示名称，历史代码标识和文件路径继续保留。

面向中国出海商家的税务研究与 AI 工作台。此仓库让资料编写者及外部 AI 无需私有仓库权限即可读取项目目标、执行方法、必要源码、数据库结构和案例。

- [阅读入口](guides/00_阅读入口.md)
- [专业引用与规则发布](guides/01_专业引用与规则发布执行指引.md)
- [案例搜集与验收](guides/02_标杆案例搜集与验收指引.md)
- [Web 与云端部署](guides/03_Web工作台与云端部署方案.md)
- [智能追问](guides/04_智能追问接入与验收.md)
- [外部 AI 连续阅读正文](https://raw.githubusercontent.com/hamliy-feng/CrossTax-reading/main/ALL_CONTEXT.md)
- [实际状态](STATUS.md)、[源版本](SOURCE_VERSION.json)、[文件清单](CONTENTS.json)

完整工程继续私有。此包不包含凭据、数据库备份、用户聊天和原始资料全集。必要代码用于理解接口与资料如何进入产品；需要维护者按私有项目完整依赖运行。

资料编写者按 guides 的模板交付 Markdown、JSON、来源清单和 SQL 提案，可提交 Pull Request。维护者复算原件 SHA、检查版本与规则条件，再在专库执行。缺少证据保留缺口，不生成虚构审核人或官方案号。

AI 可能会说错，请注意甄别。
